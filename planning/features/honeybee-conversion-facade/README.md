# honeybee-conversion-facade — router

**Scope:** Expose a clear, stable public API for converting a live Honeybee /
honeybee-ph `Model` into an in-memory `PhxProject`, without implying that a file
or serialized HBJSON dictionary is required.

**Read order:**
1. `PRD.md` — what / why (behavior and compatibility contract)
2. `STATUS.md` — current state, next step, blockers

**Origin:** ph-modeler POC application review (2026-08-14). Coordinated OpenPH
request: `openph-workspace/planning/features/phx-conversion-facade/`.
